Malayalam Hand Gesture Recognition and Translation 🗣️✍️Real-time Sign Language to Text ConversionThis repository houses the essential components for a cutting-edge, real-time hand gesture recognition system. Its primary function is to interpret hand gestures and seamlessly translate them into Malayalam alphabetic letters, aiming to bridge communication gaps and facilitate the understanding of Malayalam sign language.✨ Project Highlights ✨Our system is engineered for speed and accuracy, capable of:👁️ Detecting hand gestures from live video feeds with precision.✍️ Recognizing specific hand gestures that correspond to individual Malayalam alphabetic characters.⚡ Translating recognized gestures into their respective Malayalam characters in a matter of seconds, enabling fluid communication.This project stands as a powerful tool for enhancing accessibility and supporting the learning and application of Malayalam sign language.📂 Repository Structure 📂Navigate through the project's core components:best_model.h5: 🧠 The heart of our recognition system! This file contains the pre-trained Keras model (likely a MobileNetV2 variant) responsible for highly accurate hand gesture classification.class_mapping.json: 🗺️ Your Rosetta Stone for gestures! This JSON file meticulously maps the model's numerical outputs to their corresponding Malayalam alphabetic characters.environment.yml: 📦 A consistent environment, every time. This Conda environment definition ensures all necessary dependencies are in place for smooth development and deployment.inference22.py: 🚀 The real-time backend powerhouse! This Python script leverages the trained model and class mapping to process live image data (e.g., from a webcam), detect hands using MediaPipe, and predict/return the translated Malayalam character via a Flask API.requirments.txt: 📋 A pip friendly list of all Python package dependencies, mirroring environment.yml for flexibility.train.py: 🏋️‍♂️ The training ground! This script handles everything from hand detection and cropping (using OpenCV and MediaPipe) to data loading, defining the MobileNetV2-based model architecture, and executing the training process with smart callbacks for optimal performance.🌟 Key Features at a Glance 🌟⚡ Real-time Recognition: Experience near-instantaneous translation of gestures into text.🗣️ Malayalam Alphabet Support: Specifically fine-tuned to understand and convert gestures for the complete Malayalam alphabet.🌐 Robust Backend API: inference22.py offers a clean Flask API endpoint, making frontend integration a breeze.✋ Advanced Hand Detection: Utilizes sophisticated techniques (like MediaPipe) to precisely isolate and focus on the hand region for accurate gesture analysis.🧠 Deep Learning Powered: Built upon a highly efficient MobileNetV2 model, ensuring both speed and accuracy in classification.🛠️ Setup and Installation 🛠️Get your project up and running with these simple steps:Clone the repository:git clone <your-repository-url>

This command will launch a Flask server, typically accessible at http://127.0.0.1:5000. You can then send POST requests containing image data to the /predict endpoint for real-time translation.🚀 Backend API Endpoints 🚀The inference22.py script exposes the following API endpoints for interaction:POST /predictThis endpoint is the core of the real-time gesture translation.Accepts: A POST request with a JSON payload containing base64-encoded image data.{
  "image": "data:image/jpeg;base64,..."
}
The "image" field should contain a base64-encoded image string (e.g., from a webcam feed or file). The image is expected to contain a hand performing a sign gesture.Functionality:Decodes the incoming base64 image.Utilizes MediaPipe to detect and precisely crop the hand region from the image.Preprocesses the isolated hand region (resizing and normalization) to prepare it for the model.Feeds the preprocessed image to the TensorFlow model (best_model.h5) to predict the corresponding sign.Returns the top predicted signs along with their confidence scores.Response Example:{
  "predictions": [
    {"class": "Hello", "confidence": 0.91},
    {"class": "Thanks", "confidence": 0.06},
    {"class": "Yes", "confidence": 0.03}
  ],
  "hand_detected": true,
  "inference_time_ms": 34.12,
  "timestamp": 1720000000.0,
  "hand_box": {
    "xmin": 120,
    "ymin": 80,
    "xmax": 300,
    "ymax": 260
  }
}
The hand_box field provides the bounding box coordinates of the detected hand, if available.GET /healthThis endpoint provides a simple health check for the backend service.Accepts: A GET request.Functionality: Returns the current status of the service, including performance metrics.Response Example:{
  "status": "ok",
  "avg_inference_time_ms": 35.50,
  "total_predictions": 1500
}
This helps in monitoring the service's availability and performance.📈 Training the Model 📊Interested in retraining the model or training it with new data?Prepare your dataset: Organize your image dataset in a structure compatible with ImageDataGenerator in train.py (e.g., data/train and data/validation directories, each containing subdirectories for every distinct class/letter).Execute the training script:python train.py
Upon completion, a new model will be saved as sign_language_model_gray.h5. Remember to update inference22.py to point to this new model if you intend to deploy it.🔗 Usage: Frontend Integration 🔗This repository provides the robust backend and training infrastructure.
